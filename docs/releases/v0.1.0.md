# openFTTH 0.1.0 (beta)

The first public beta of openFTTH for Windows: design a fibre-to-the-home network on your own
PC, with an AI crew or with no AI at all.

## Install

Download `openFTTH-0.1.0-windows-x64.zip` (check it against the `.sha256` file), unzip it
anywhere, for example in your Documents folder, and run `openFTTH\openftth.exe`. Nothing else
needs installing: Node and Python come inside the folder. The app is not code-signed yet, so
Windows SmartScreen may warn: choose **More info → Run anyway**. Your projects live in
`%USERPROFILE%\.openftth`, so a later version can be unzipped beside this one.

## What is in it

- **Design automatically (free, no AI):** streets, homes, POPs, cabinets, FATs, feeder,
  distribution and drop routes, chambers, cable sizes and fibre assignment, checked against
  the rulebook.
- **An AI crew if you want one:** Surveyor, Planner, Checker and Drafter, on Claude CLI, Codex
  CLI, OpenRouter, any OpenAI-compatible key or a local Ollama model. Keys stay in Windows
  Credential Manager.
- **Manual mode:** add and move sites, draw, split and join cables, edit splices, draw keep-out
  and no-dig zones, undo and redo, then complete the network around your layout.
- **Design scenarios:** GPON and XGS-PON budgets, centralised, cascaded and point-to-point
  architectures, aerial spans on existing poles and façade routes, build phases and take-rate,
  risers in blocks of flats, priced side by side.
- **Deliverables:** plan sheets (PDF, A3/A1) and a DXF drawing, bill of quantities (per phase
  too), cable schedule, port report, splice schedule, GeoPackage, and export profiles for your
  own schema (GeoPackage, Shapefile, CSV).
- **Rulebooks:** generic GPON, generic XGS-PON, Belgium and Norway presets, every value with
  its source.
- **Open to other AI apps:** a local MCP link for Claude, Cursor and VS Code.

## Beta

Everything in 0.1 is beta: the presets carry typical values, so set your own prices and local
rules. Please report problems on GitHub Issues; security issues go through the private advisory
form (see SECURITY.md).
